# M5-01 — MCP Client (stdio) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A generic MCP client that spawns a local server as a subprocess, speaks JSON-RPC over its pipes, and lists and calls its tools and resources — with no process ever outliving the app.

**Architecture:** `SpawnedProcess` puts each server in a process group of its own; `ProcessLedger` records every group so the next launch can reap what a crash left; `MCPConnection` resolves requests by id from a reader task, so no wait is ever on a file descriptor; `MCPServer` owns the lifecycle policy; `MCPHost` reaps at launch and stops everything at quit. stdio only.

**Tech Stack:** Swift 6, Darwin `posix_spawn`/`killpg`/`proc_pidinfo`, Swift Testing, XcodeGen, SwiftLint. No package dependencies.

**Spec:** [`docs/superpowers/specs/2026-10-09-m5-01-mcp-stdio-client-design.md`](../specs/2026-10-09-m5-01-mcp-stdio-client-design.md) — read its **Amended during the build** table first; where the spec and `DECISIONS.md` disagree, the decision record is current.

**Provenance.** Every code block below was generated by a script from a tree that had already passed `make build && make test && make lint` and the live checks in Tasks 6 and 8, and every guard was mutation-tested (table at the end). Where a step says something passes, it was run — not predicted. The round trip was checked: each `Create` block was extracted back out of this file and compared byte for byte with the file it describes.

## Review Focus

Inputs and conditions the spec implies that no task's tests exercise, most likely first. Each is
either pinned by a test added to its owning task or stated here as accepted behaviour.

1. **A definition environment key that is empty or contains `=`** — `posix_spawn` would build a
   malformed `envp` entry, and the child would see a different variable than the user typed.
   Expected: the key is dropped. *Pinned in Task 2* (`invalidKeysAreDropped`).
2. **A relative command such as `./server`** — a Finder-launched app's working directory is `/`, so
   it would resolve somewhere the user never meant. Expected: refused as `.commandNotFound`; M5-02
   asks for an absolute path or a bare name. *Pinned in Task 2* (`relativePathIsRefused`).
3. **An `npx` first run that downloads for longer than the 20 s startup deadline.** Expected:
   `.timedOut`, counted as a failure; the download continues into npm's cache, so the next attempt
   is fast. Accepted — `hangOnInitialize` covers the mechanism; M5-02's connection test should say
   "first run may be slow".
4. **A server that exits cleanly (status 0) while idle** — some servers have idle timeouts. Expected:
   counted as a failure like any exit, and restarted by the next request. Accepted; three idle exits
   within a minute is not a pattern any known server has. `crashThenRestart` covers the path.
5. **A reply carrying an id this client never sent, or a second reply to the same id.** Expected:
   dropped, and the connection carries on. The codec half is pinned by `classifies`; the
   connection half by a stub tool that answers twice. *Pinned in Task 5* (`duplicateReplyIsDropped`).

```swift
import Foundation

/// Any JSON value, as a Swift value.
///
/// **MCP results are passed through rather than modelled** (D-234). A tool's
/// `content` blocks, a resource's body and a tool's `inputSchema` are the
/// server's business and M5-03's to interpret; this layer moves them. Typing
/// them here would mean every new content kind a spec revision adds — 2025-06-18
/// added `resource_link`, 2025-11-25 added more — fails to decode in a client
/// that never needed to read it.
///
/// **Integers are their own case.** A JSON-RPC id is an integer, and routing a
/// reply through `Double` would make "is this the id I sent" a floating-point
/// comparison.
public enum JSONValue: Sendable, Equatable, Codable {
    case null
    case bool(Bool)
    case integer(Int)
    case number(Double)
    case string(String)
    case array([JSONValue])
    case object([String: JSONValue])

    public init(from decoder: Decoder) throws {
        let container = try decoder.singleValueContainer()
        if container.decodeNil() {
            self = .null
        } else if let value = try? container.decode(Bool.self) {
            self = .bool(value)
        } else if let value = try? container.decode(Int.self) {
            self = .integer(value)
        } else if let value = try? container.decode(Double.self) {
            self = .number(value)
        } else if let value = try? container.decode(String.self) {
            self = .string(value)
        } else if let value = try? container.decode([JSONValue].self) {
            self = .array(value)
        } else {
            self = .object(try container.decode([String: JSONValue].self))
        }
    }

    public func encode(to encoder: Encoder) throws {
        var container = encoder.singleValueContainer()
        switch self {
        case .null: try container.encodeNil()
        case .bool(let value): try container.encode(value)
        case .integer(let value): try container.encode(value)
        case .number(let value): try container.encode(value)
        case .string(let value): try container.encode(value)
        case .array(let value): try container.encode(value)
        case .object(let value): try container.encode(value)
        }
    }

    /// The member named `key`, when this is an object that has one.
    public subscript(key: String) -> JSONValue? {
        guard case .object(let members) = self else { return nil }
        return members[key]
    }

    public var stringValue: String? {
        guard case .string(let value) = self else { return nil }
        return value
    }

    public var boolValue: Bool? {
        guard case .bool(let value) = self else { return nil }
        return value
    }

    public var arrayValue: [JSONValue]? {
        guard case .array(let value) = self else { return nil }
        return value
    }
}
```

```swift
import Foundation

/// The only error the MCP client throws (D-240).
///
/// **No case carries a `String`.** Everything a server can say — a JSON-RPC
/// error message, a line on stderr — is text the server wrote, and a server's
/// text can contain whatever a tool returned: ticket titles, calendar entries,
/// a token echoed from its own environment. `SourceError` made the same choice
/// for the same reason (D-165); keeping it here makes "an `MCPError` is always
/// safe to log" a property of the type rather than of every call site.
///
/// **A tool that reports failure is not an `MCPError`.** A `tools/call` result
/// with `isError: true` means the transport worked and the tool said no; it is
/// returned in `MCPToolResult.isError`. These cases are the transport failing.
public enum MCPError: Error, Equatable, Sendable {
    /// The command is not on the child's `PATH`, or is not executable.
    case commandNotFound

    /// `posix_spawn` refused for any other reason.
    case launchFailed(errno: Int32)

    /// The process exited before it answered `initialize`.
    ///
    /// `status` is the raw `waitpid` status: a server that prints usage and
    /// exits 1 and one that was killed by a signal both land here, and M5-02's
    /// connection test is what tells them apart for the user.
    case exitedDuringStartup(status: Int32)

    /// The process exited while it was serving.
    case crashed

    /// Three failures — crashes or timeouts — inside the failure window (D-237).
    ///
    /// Every request throws this until `MCPServer.restart()`. **Not named for
    /// crashes alone,** because a server that hangs every time is the same
    /// problem with a slower symptom, and it counts the same way.
    case failedRepeatedly

    /// The startup or request deadline passed.
    case timedOut

    /// The server negotiated a protocol version this client does not speak.
    case unsupportedProtocolVersion

    /// A JSON-RPC error response. The server's message is discarded.
    case serverError(code: Int)

    /// The server broke the protocol in a way this client will not work around.
    case protocolViolation(ProtocolViolation)

    /// The server was stopped — by `stop()`, by app quit, or because another
    /// request on the same connection timed out — while this request waited.
    case stopped

    public enum ProtocolViolation: Equatable, Sendable {
        /// A single line exceeded `JSONRPCFramer.maximumLineLength`.
        case oversizedMessage
        /// A result was missing a field the protocol requires.
        case malformedResult
        /// A list kept returning `nextCursor` past `MCPProtocol.maximumPages`.
        case paginationRunaway
        /// The caller's params could not be encoded — a non-finite number.
        case unencodableRequest
    }
}
```

```swift
import Foundation

/// Protocol constants, written once.
public enum MCPProtocol {
    /// The version this client asks for.
    ///
    /// **Measured, not remembered** (spec, D-234). Against
    /// `@modelcontextprotocol/server-everything` 2.0.0 on 2026-10-09, a server
    /// echoes any version it supports and answers an unknown one with its own
    /// latest — so asking for the newest version is what lets a current server
    /// agree, and an older server answers with the older version it speaks.
    public static let requestedVersion = "2025-11-25"

    /// Every version whose `initialize`, `ping`, `tools/*` and `resources/*`
    /// shapes this client reads correctly.
    ///
    /// The four differ in what they *add* — structured tool output, resource
    /// links, tasks — and those additions arrive inside `JSONValue` fields this
    /// layer passes through rather than decodes, so none of them can break it.
    public static let supportedVersions: Set<String> = [
        "2025-11-25", "2025-06-18", "2025-03-26", "2024-11-05",
    ]

    /// `tools/list` and `resources/list` stop following `nextCursor` here.
    ///
    /// A server that always returns a cursor would otherwise keep a refresh
    /// pass busy forever. Twenty pages is several hundred tools.
    public static let maximumPages = 20
}

        self.name = name
        title = value["title"]?.stringValue
```

```swift
import Foundation

/// One JSON-RPC 2.0 message, in either direction.
///
/// MCP's stdio transport is newline-delimited JSON-RPC: one message per line,
/// no embedded newlines. `JSONEncoder` never emits a raw newline (it escapes
/// them inside strings), so `encodedLine()` cannot produce a line that splits.
enum JSONRPCMessage: Equatable, Sendable {
    case request(id: Int, method: String, params: JSONValue?)
    case notification(method: String, params: JSONValue?)
    case response(id: Int, result: JSONValue)
    case errorResponse(id: Int, code: Int)

    /// A request the *server* sent, whose id may be a string.
    ///
    /// Kept apart from `.request` because its id is echoed back verbatim and
    /// never matched against the pending table: JSON-RPC lets each side choose
    /// its own ids, so a server's `1` and ours are unrelated.
    case serverRequest(id: JSONValue, method: String)

    /// The message as one line, newline included.
    func encodedLine() throws -> Data {
        var data = try Self.encoder.encode(envelope())
        data.append(0x0A)
        return data
    }

    /// The reply to a server request: `{}` for `ping`, which MCP requires the
    /// receiving side to answer, and `-32601 method not found` for everything
    /// else, since this client declares no capabilities.
    static func reply(toServerRequest id: JSONValue, method: String) -> JSONValue {
        if method == "ping" {
            return .object(["jsonrpc": .string("2.0"), "id": id, "result": .object([:])])
        }
        return .object([
            "jsonrpc": .string("2.0"), "id": id,
            "error": .object([
                "code": .integer(methodNotFound), "message": .string("Method not found"),
            ]),
        ])
    }

    static let methodNotFound = -32_601

    /// Classify one decoded line, or `nil` for anything that is not a message
    /// this client can act on.
    ///
    /// A response whose id is not an integer is unclassifiable rather than an
    /// error: this client only ever sends integer ids, so no pending request
    /// could match it.
    static func classify(_ value: JSONValue) -> JSONRPCMessage? {
        let method = value["method"]?.stringValue
        switch (value["id"], method) {
        case (.some(let id), .some(let method)) where id != .null:
            return .serverRequest(id: id, method: method)
        case (nil, .some(let method)):
            return .notification(method: method, params: value["params"])
        case (.some(.integer(let id)), nil):
            if let error = value["error"] {
                guard case .integer(let code) = error["code"] else { return nil }
                return .errorResponse(id: id, code: code)
            }
            guard let result = value["result"] else { return nil }
            return .response(id: id, result: result)
        default:
            return nil
        }
    }

    static func decode(line: Data) -> JSONRPCMessage? {
        guard let value = try? JSONDecoder().decode(JSONValue.self, from: line) else {
            return nil
        }
        return classify(value)
    }

    private func envelope() -> JSONValue {
        var members: [String: JSONValue] = ["jsonrpc": .string("2.0")]
        switch self {
        case .request(let id, let method, let params):
            members["id"] = .integer(id)
            members["method"] = .string(method)
            if let params { members["params"] = params }
        case .notification(let method, let params):
            members["method"] = .string(method)
            if let params { members["params"] = params }
        case .response(let id, let result):
            members["id"] = .integer(id)
            members["result"] = result
        case .errorResponse(let id, let code):
            members["id"] = .integer(id)
            members["error"] = .object(["code": .integer(code), "message": .string("")])
        case .serverRequest(let id, let method):
            return Self.reply(toServerRequest: id, method: method)
        }
        return .object(members)
    }

    /// `.sortedKeys` so a message's bytes are a function of its content — a test
    /// can compare lines, and nothing depends on dictionary hash order, which
    /// differs between processes.
    private static let encoder: JSONEncoder = {
        let encoder = JSONEncoder()
        encoder.outputFormatting = [.sortedKeys, .withoutEscapingSlashes]
        return encoder
    }()
}

/// Splits a byte stream into lines, refusing any line longer than the cap.
///
/// **The cap is what keeps a runaway server from exhausting memory.** Without
/// it, a server that writes without ever writing a newline grows this buffer
/// until the app is killed — which is the "takes the app with it" failure the
/// task's second criterion forbids.
struct JSONRPCFramer {
    /// 8 MB. A resource body is the largest thing that legitimately arrives in
    /// one message; this is far beyond any page or calendar a stand-up needs.
    static let maximumLineLength = 8 * 1024 * 1024

    private var buffer = Data()
    private let limit: Int

    init(limit: Int = maximumLineLength) {
        self.limit = limit
    }

    enum Output: Equatable {
        case line(Data)
        case oversized
    }

    /// Append a chunk and return every complete line it finished.
    ///
    /// After `.oversized` the framer is spent: the stream has no reliable
    /// boundary to resynchronize on, so the connection ends.
    ///
    /// **Only the new bytes are searched.** What was buffered before this chunk
    /// held no newline, so rescanning it would make a large message arriving in
    /// pipe-sized chunks quadratic: an 8 MB line in 64 KB reads is 128 scans of
    /// a growing buffer.
    mutating func append(_ chunk: Data) -> [Output] {
        var searchFrom = buffer.endIndex
        buffer.append(chunk)
        var lineStart = buffer.startIndex
        var lines: [Output] = []
        while let newline = buffer[searchFrom...].firstIndex(of: 0x0A) {
            var line = buffer[lineStart..<newline]
            lineStart = buffer.index(after: newline)
            searchFrom = lineStart
            if line.last == 0x0D { line = line.dropLast() }
            guard line.count <= limit else { return lines + [.oversized] }
            if !line.isEmpty { lines.append(.line(Data(line))) }
        }
        if lineStart != buffer.startIndex { buffer = Data(buffer[lineStart...]) }
        if buffer.count > limit { lines.append(.oversized) }
        return lines
    }
```

```swift
import Foundation

/// What to run, and how to talk to it.
///
/// **Not persisted, and holds no secret yet.** M5-02 stores definitions and
/// moves environment secrets to the Keychain (§8); this task needs only the
/// value a spawn takes.
public struct MCPServerDefinition: Sendable, Equatable {
    /// Stable identity, logged in place of the command: a command line can
    /// carry a token as an argument, and an id never does.
    public let id: String
    /// A bare name resolved against the child's `PATH`, or a path.
    public let command: String
    public let arguments: [String]
    /// Applied on top of the child's base environment, so it can override
    /// `PATH` among anything else.
    public let environment: [String: String]

    public init(
        id: String, command: String, arguments: [String] = [],
        environment: [String: String] = [:]
    ) {
        self.id = id
        self.command = command
        self.arguments = arguments
        self.environment = environment
    }
}

/// The environment and executable a server is spawned with (D-239).
///
/// **The app's own environment is never passed through.** A Finder-launched
/// app's environment is launchd's, not the user's shell's, so passing it buys
/// nothing; and under `xctest` it carried `OS_ACTIVITY_DT_MODE`, which once
/// made a subprocess test fail for reasons unrelated to what it tested.
struct ChildLaunch: Equatable {
    let executable: String
    let arguments: [String]
    let environment: [String: String]

    /// Where Homebrew installs on Apple silicon and on Intel, ahead of the
    /// system directories a Finder-launched app gets.
    static let basePath = "/opt/homebrew/bin:/usr/local/bin:/usr/bin:/bin:/usr/sbin:/sbin"

    /// The handful of variables a server needs to find its home directory and
    /// a scratch directory, and to decode text.
    static let inheritedKeys = ["HOME", "USER", "LOGNAME", "LANG", "TMPDIR"]

    /// - Returns: `nil` when the command cannot be resolved to an executable.
    static func resolve(
        _ definition: MCPServerDefinition,
        parentEnvironment: [String: String] = ProcessInfo.processInfo.environment,
        isExecutable: (String) -> Bool = { FileManager.default.isExecutableFile(atPath: $0) }
    ) -> ChildLaunch? {
        var environment = inheritedKeys.reduce(into: [String: String]()) { result, key in
            result[key] = parentEnvironment[key]
        }
        // **The command's own directory goes first** (D-239, measured
        // 2026-10-09). `npx` is a `#!/usr/bin/env node` script, so it needs
        // `node` on `PATH` as well as being found itself — and an nvm, Volta or
        // asdf install keeps both in one `bin` directory that no fixed list
        // contains. With `PATH=/usr/bin:/bin`, an absolute nvm `npx` fails with
        // `env: node: No such file or directory`; with its own directory
        // prepended it runs. The directory of the path as given, not of its
        // symlink target: nvm's `npx` resolves into `lib/node_modules`, where
        // there is no `node`.
        var path = basePath
        if definition.command.hasPrefix("/") {
            let directory = (definition.command as NSString).deletingLastPathComponent
            path = "\(directory):\(basePath)"
        }
        environment["PATH"] = path
        // An empty key, or one containing `=`, cannot be expressed in an
        // `envp` entry: `A=B=c` reads back as `A` with value `B=c`. Dropped,
        // so the child never sees a variable the user did not write.
        let expressible = definition.environment.filter { !$0.key.isEmpty && !$0.key.contains("=") }
        environment.merge(expressible) { _, override in override }

        guard
            let executable = executablePath(
                for: definition.command, path: environment["PATH"] ?? path,
                isExecutable: isExecutable)
        else { return nil }
        return ChildLaunch(
            executable: executable, arguments: definition.arguments, environment: environment)
    }

    /// An absolute path is used as given; a bare name is searched for on
    /// `path` — **the child's `PATH`, not the app's**, so what the app finds is
    /// what the child would.
    ///
    /// **A relative path is refused.** It would resolve against the app's
    /// working directory, which for a Finder-launched app is `/` — somewhere no
    /// user means when they type `./server`.
    private static func executablePath(
        for command: String, path: String, isExecutable: (String) -> Bool
    ) -> String? {
        if command.contains("/") {
            return command.hasPrefix("/") && isExecutable(command) ? command : nil
        }
        for directory in path.split(separator: ":") where !directory.isEmpty {
            let candidate = "\(directory)/\(command)"
            if isExecutable(candidate) { return candidate }
        }
        return nil
    }
}
```

```swift
import Darwin
import Foundation

// A deliberately badly behaved MCP server, for M5-01's tests (D-241).
//
// A real subprocess rather than an in-process double, because what M5-01 has to
// get right is process behaviour — pipes, groups, signals, exit — and a double
// that never spawned anything could not fail on any of it.
//
// Per-server behaviour is chosen at launch with `--mode a,b,…`; per-call
// behaviour by which tool is called. Modes:
//
//   exit-before-init   exit 3 before reading anything
//   hang-on-init       read `initialize`, never answer
//   bad-version        answer `initialize` with a version no client speaks
//   garbage-stdout     write a non-JSON line before every reply
//   flood-stderr       write 256 KB to stderr before every reply
//   ignore-eof         on stdin EOF, keep running
//   ignore-term        ignore SIGTERM
//   spawn-grandchild   start `/bin/sleep 600` in this process group at launch
//   paginate-forever   every `tools/list` page has a `nextCursor`
//   stop-reading-stdin after answering a `ping`, never read stdin again
//
// Tools: echo, fail (isError), crash (exit 1), hang, grandchild (its pid),
// big (a 64 KB reply), ask-client (sends `sampling/createMessage` to the client
// and reports the reply), ping-client (sends `ping` and reports the reply),
// open-fds (which descriptors this process holds), reply-then-exit (a 1 MB
// reply, then exit 0), reply-twice (the same reply, sent twice).

let modes: Set<String> = {
    let arguments = CommandLine.arguments
    guard let index = arguments.firstIndex(of: "--mode"), index + 1 < arguments.count else {
        return []
    }
    return Set(arguments[index + 1].split(separator: ",").map(String.init))
}()

func emit(_ object: [String: Any]) {
    if modes.contains("flood-stderr") {
        FileHandle.standardError.write(Data(repeating: 0x45, count: 256 * 1024))
    }
    if modes.contains("garbage-stdout") {
        FileHandle.standardOutput.write(Data("this is not json\n".utf8))
    }
    var data = (try? JSONSerialization.data(withJSONObject: object)) ?? Data()
    data.append(0x0A)
    FileHandle.standardOutput.write(data)
}

func reply(_ id: Any, _ result: [String: Any]) {
    emit(["jsonrpc": "2.0", "id": id, "result": result])
}

func fail(_ id: Any, code: Int) {
    emit(["jsonrpc": "2.0", "id": id, "error": ["code": code, "message": "stub error"]])
}

func text(_ value: String, isError: Bool = false) -> [String: Any] {
    ["content": [["type": "text", "text": value]], "isError": isError]
}

func hangForever() -> Never {
    while true { sleep(60) }
}

var grandchild: pid_t = 0

@MainActor func spawnGrandchild() {
    // No `POSIX_SPAWN_SETPGROUP` and default descriptors: like `npx`'s `node`,
    // the grandchild shares this group and holds this process's stdout open.
    let argv: [UnsafeMutablePointer<CChar>?] = [strdup("/bin/sleep"), strdup("600"), nil]
    defer {
        for pointer in argv { free(pointer) }
    }
    posix_spawn(&grandchild, "/bin/sleep", nil, nil, argv, environ)
}

func nextMessage() -> [String: Any]? {
    guard let line = Swift.readLine(strippingNewline: true) else { return nil }
    return (try? JSONSerialization.jsonObject(with: Data(line.utf8))) as? [String: Any]
}

/// Ask the client something and return its reply, for the two tools that
/// exercise server-to-client requests.
func askClient(_ method: String) -> String {
    emit(["jsonrpc": "2.0", "id": "stub-1", "method": method, "params": [:]])
    guard let answer = nextMessage() else { return "no answer" }
    if let error = answer["error"] as? [String: Any], let code = error["code"] as? Int {
        return "error \(code)"
    }
    return answer["result"] != nil ? "result" : "neither"
}

let toolPages: [[[String: Any]]] = [
    [["name": "echo", "inputSchema": ["type": "object"]]],
    [
        "fail", "crash", "hang", "grandchild", "big", "ask-client", "ping-client", "open-fds",
        "reply-then-exit", "reply-twice",
    ].map {
        ["name": $0, "inputSchema": ["type": "object"]]
    },
]

@MainActor func listTools(_ id: Any, cursor: String?) {
    if modes.contains("paginate-forever") {
        reply(id, ["tools": toolPages[0], "nextCursor": UUID().uuidString])
    } else if cursor == "page-2" {
        reply(id, ["tools": toolPages[1]])
    } else {
        reply(id, ["tools": toolPages[0], "nextCursor": "page-2"])
    }
}

@MainActor func callTool(_ id: Any, name: String, arguments: [String: Any]) {
    switch name {
    case "echo": reply(id, text(arguments["text"] as? String ?? ""))
    case "fail": reply(id, text("the tool failed", isError: true))
```

```swift
import Darwin

/// A process, identified so that a reused pid is a different identity.
///
/// **A pid alone is not an identity.** macOS recycles pids, so a ledger entry
/// left by a crash weeks ago may name a pid that now belongs to an unrelated
/// process. The start time is what tells them apart: two processes can share a
/// pid, never a pid *and* a start time (D-236).
struct ProcessIdentity: Codable, Equatable, Sendable {
    let pid: Int32
    /// Seconds and microseconds since the epoch, from `proc_pidinfo`.
    let startSeconds: UInt64
    let startMicroseconds: UInt64

    /// The identity of `pid` as the kernel reports it now, or `nil` when no
    /// such process exists.
    static func current(of pid: Int32) -> ProcessIdentity? {
        var info = proc_bsdinfo()
        let size = Int32(MemoryLayout<proc_bsdinfo>.size)
        guard proc_pidinfo(pid, PROC_PIDTBSDINFO, 0, &info, size) == size else { return nil }
        return ProcessIdentity(
            pid: pid, startSeconds: info.pbi_start_tvsec,
            startMicroseconds: info.pbi_start_tvusec)
    }

    /// This process.
    static var this: ProcessIdentity? { current(of: getpid()) }

    /// Is the process this identity names still running?
    var isAlive: Bool { Self.current(of: pid) == self }
}

/// Process-group primitives, named for what they mean.
enum ProcessGroup {
    /// Does any process in group `pgid` exist?
    ///
    /// `killpg` with signal 0 checks without sending. `EPERM` means a member
    /// exists that this user may not signal — it exists, so it counts.
    static func hasMembers(_ pgid: Int32) -> Bool {
        if killpg(pgid, 0) == 0 { return true }
        return errno == EPERM
    }

    static func signal(_ pgid: Int32, _ signal: Int32) {
        _ = killpg(pgid, signal)
    }

    /// Wait up to `timeout` for the group to empty, polling every 10 ms.
    ///
    /// **Polling, deliberately.** There is no kernel notification for "the last
    /// member of a group exited": kqueue watches a pid, and the members of an
    /// `npx` group are not ours to enumerate cheaply. Ten milliseconds is
    /// invisible against a grace period measured in seconds.
    static func waitUntilEmpty(_ pgid: Int32, timeout: Duration) async -> Bool {
        let deadline = ContinuousClock.now + timeout
        while hasMembers(pgid) {
            guard ContinuousClock.now < deadline else { return false }
            try? await Task.sleep(for: .milliseconds(10))
        }
        return true
    }
}
```

```swift
import Darwin
import Foundation

/// A server process in a process group of its own (D-235).
///
/// **`posix_spawn`, not `Foundation.Process`,** for two flags `Process` does
/// not expose:
///
/// - `POSIX_SPAWN_SETPGROUP` makes the child a group leader, so one `killpg`
///   reaches everything it started. `npx` runs the server as a `node` child,
///   and killing `npx` alone leaves `node` running — the leak this task exists
///   to prevent, on exactly the servers M5-03 needs.
/// - `POSIX_SPAWN_CLOEXEC_DEFAULT` gives the child stdin, stdout and stderr and
///   nothing else. Without it a server inherits every descriptor the app has
///   open, including another server's pipes — and a server holding a copy of a
///   second server's stdout keeps that pipe open after the second one dies, so
///   its EOF never arrives.
///
/// Three threads per process, none from the cooperative pool: one blocked in
/// `waitpid` and one in `read` per output pipe. Blocking is what they are for,
/// and blocking a pool thread is what this design exists to avoid (D-238).
final class SpawnedProcess: @unchecked Sendable {
    /// The process id, which is also its group id.
    let pid: Int32
    let identity: ProcessIdentity
    let standardOutput: AsyncStream<Data>
    let standardError: AsyncStream<Data>

    /// The raw `waitpid` status, once the leader has exited and been reaped.
    let exitStatus: Task<Int32, Never>

    private let stdinFD: Int32
    /// Writes block, deliberately, on this queue and nowhere else (D-238).
    private let writer: DispatchQueue
    /// Read and written only on `writer`, whose serial order is its lock: a
    /// close can never interleave with a write in progress.
    private var stdinClosed = false

    private init(
        pid: Int32, stdinFD: Int32, stdoutFD: Int32, stderrFD: Int32
    ) {
        self.pid = pid
        // A process that has already exited may not report a start time; the
        // zero identity can then never match a live leader, so a reap treats
        // it by group membership alone — which is the right answer for a
        // process that is gone.
        identity =
            ProcessIdentity.current(of: pid)
            ?? ProcessIdentity(pid: pid, startSeconds: 0, startMicroseconds: 0)
        self.stdinFD = stdinFD
        writer = DispatchQueue(label: "com.lgabrielgr.steno.mcp.writer.\(pid)")
        standardOutput = Self.reader(stdoutFD)
        standardError = Self.reader(stderrFD)
        exitStatus = Self.waiter(pid)
    }

    /// Spawn `launch` in a new process group with only fds 0, 1 and 2.
    static func spawn(_ launch: ChildLaunch) throws(MCPError) -> SpawnedProcess {
        let pipes = try makePipes()
        var pid: pid_t = 0
        let variables = launch.environment.map { "\($0.key)=\($0.value)" }.sorted()
        let result = withSpawnAttributes(pipes: pipes) { actions, attributes in
            withCStrings([launch.executable] + launch.arguments) { argv in
                withCStrings(variables) { envp in
                    posix_spawn(&pid, launch.executable, &actions, &attributes, argv, envp)
                }
            }
        }
        // The child's ends belong to the child now (or to nobody, on failure).
        close(pipes.stdin.read)
        close(pipes.stdout.write)
        close(pipes.stderr.write)

        guard result == 0 else {
            close(pipes.stdin.write)
            close(pipes.stdout.read)
            close(pipes.stderr.read)
            switch result {
            case ENOENT, EACCES, ENOEXEC: throw .commandNotFound
            default: throw .launchFailed(errno: result)
            }
        }
        return SpawnedProcess(
            pid: pid, stdinFD: pipes.stdin.write, stdoutFD: pipes.stdout.read,
            stderrFD: pipes.stderr.read)
    }

    /// Write `data` to the child's stdin, blocking the writer queue — never the
    /// caller — until it is accepted or the pipe breaks.
    ///
    /// **A blocking write on a queue of its own, not `O_NONBLOCK`** (D-238). A
    /// wedged server stops reading and its pipe buffer fills; a write that
    /// blocks there blocks only this queue, while the request awaiting it is
    /// resumed by its deadline. The write unblocks when the group is killed —
    /// the read end closes and the write fails with `EPIPE` — which
    /// `MCPServer` does after any timeout.
    func write(_ data: Data, completion: @escaping @Sendable (Bool) -> Void) {
        writer.async { [self] in
            completion(writeAll(data))
        }
    }

    /// Close the child's stdin — the MCP-specified "please exit" — after any
    /// write already queued.
    func closeStandardInput() {
        writer.async { [self] in
            guard !stdinClosed else { return }
            stdinClosed = true
            close(stdinFD)
        }
    }

    /// Stop the whole group: close stdin, wait, `SIGTERM`, wait, `SIGKILL`.
    ///
    /// Each wait ends as soon as the group is empty. **The group, not the
    /// leader:** `npx` can exit on EOF while its `node` child lingers, and a
    /// stop that only watched the leader would report success over a leak.
    ///
    /// - Returns: `true` once the group is confirmed empty. `false` means the
    ///   budget ran out with a member still alive, and the ledger keeps the
    ///   entry for the next launch.
    func terminate(grace: Duration) async -> Bool {
        closeStandardInput()
        if await ProcessGroup.waitUntilEmpty(pid, timeout: grace) { return true }
        ProcessGroup.signal(pid, SIGTERM)
        if await ProcessGroup.waitUntilEmpty(pid, timeout: grace) { return true }
        ProcessGroup.signal(pid, SIGKILL)
        return await ProcessGroup.waitUntilEmpty(pid, timeout: grace)
    }

    /// `SIGKILL` the group now — for a leader that already crashed, whose
    /// remaining members have no reason to be asked politely.
    func killGroup(timeout: Duration) async -> Bool {
        ProcessGroup.signal(pid, SIGKILL)
        return await ProcessGroup.waitUntilEmpty(pid, timeout: timeout)
    }

    private func writeAll(_ data: Data) -> Bool {
        guard !stdinClosed else { return false }
        return data.withUnsafeBytes { buffer -> Bool in
            guard let base = buffer.baseAddress else { return true }
            var offset = 0
            while offset < buffer.count {
                let written = Darwin.write(stdinFD, base + offset, buffer.count - offset)
                if written < 0 {
                    if errno == EINTR { continue }
                    return false
                }
                offset += written
            }
            return true
        }
    }

    // MARK: - Threads

    private static func reader(_ descriptor: Int32) -> AsyncStream<Data> {
        let (stream, continuation) = AsyncStream<Data>.makeStream()
        let thread = Thread {
            var buffer = [UInt8](repeating: 0, count: 64 * 1024)
            while true {
                let count = buffer.withUnsafeMutableBytes {
                    read(descriptor, $0.baseAddress, $0.count)
                }
                if count > 0 {
                    continuation.yield(Data(buffer[0..<count]))
                } else if count < 0 && errno == EINTR {
                    continue
                } else {
                    break
                }
            }
            close(descriptor)
            continuation.finish()
        }
        thread.name = "com.lgabrielgr.steno.mcp.reader"
        thread.start()
        return stream
    }

    /// Reap the leader, so it never lingers as a zombie, and publish its status.
    private static func waiter(_ pid: Int32) -> Task<Int32, Never> {
        let (stream, continuation) = AsyncStream<Int32>.makeStream()
        let thread = Thread {
            var status: Int32 = 0
            while waitpid(pid, &status, 0) < 0 && errno == EINTR {}
            continuation.yield(status)
            continuation.finish()
        }
        thread.name = "com.lgabrielgr.steno.mcp.waiter"
        thread.start()
        return Task {
            for await status in stream { return status }
            return -1
        }
    }

    // MARK: - posix_spawn plumbing

    private struct Pipe {
        let read: Int32
        let write: Int32
    }

    private struct Pipes {
        let stdin: Pipe
        let stdout: Pipe
        let stderr: Pipe
    }

    private static func makePipes() throws(MCPError) -> Pipes {
        var made: [Pipe] = []
        for _ in 0..<3 {
            var fds: [Int32] = [0, 0]
            guard pipe(&fds) == 0 else {
                let failure = errno
                for pipe in made {
                    close(pipe.read)
                    close(pipe.write)
                }
                throw .launchFailed(errno: failure)
            }
            // Close-on-exec in the parent too: a process spawned elsewhere in
            // the app, by something without `POSIX_SPAWN_CLOEXEC_DEFAULT`, must
            // not inherit a server's pipe and hold it open.
            for descriptor in fds { _ = fcntl(descriptor, F_SETFD, FD_CLOEXEC) }
            made.append(Pipe(read: fds[0], write: fds[1]))
        }
        // A write to a server that has exited raises `SIGPIPE`, whose default
        // action terminates the *writer* — the app. This turns it into `EPIPE`
        // on this descriptor alone, so a crashed server cannot take the app
        // down with it (the task's second criterion).
        _ = fcntl(made[0].write, F_SETNOSIGPIPE, 1)
        return Pipes(stdin: made[0], stdout: made[1], stderr: made[2])
    }

    private static func withSpawnAttributes(
        pipes: Pipes,
        _ body: (inout posix_spawn_file_actions_t?, inout posix_spawnattr_t?) -> Int32
    ) -> Int32 {
        var actions: posix_spawn_file_actions_t?
        posix_spawn_file_actions_init(&actions)
        defer { posix_spawn_file_actions_destroy(&actions) }
        posix_spawn_file_actions_adddup2(&actions, pipes.stdin.read, STDIN_FILENO)
        posix_spawn_file_actions_adddup2(&actions, pipes.stdout.write, STDOUT_FILENO)
        posix_spawn_file_actions_adddup2(&actions, pipes.stderr.write, STDERR_FILENO)

        var attributes: posix_spawnattr_t?
        posix_spawnattr_init(&attributes)
        defer { posix_spawnattr_destroy(&attributes) }
        // Group 0 means "a new group whose id is the child's pid".
        posix_spawnattr_setpgroup(&attributes, 0)
        // Signal dispositions the app set — an ignored `SIGPIPE`, say — would
        // otherwise survive `exec` into the server. Reset all, block none.
        var everything = sigset_t()
        sigfillset(&everything)
        posix_spawnattr_setsigdefault(&attributes, &everything)
        var nothing = sigset_t()
        sigemptyset(&nothing)
        posix_spawnattr_setsigmask(&attributes, &nothing)
        let flags =
            POSIX_SPAWN_SETPGROUP | POSIX_SPAWN_CLOEXEC_DEFAULT | POSIX_SPAWN_SETSIGDEF
            | POSIX_SPAWN_SETSIGMASK
        posix_spawnattr_setflags(&attributes, Int16(flags))

        return body(&actions, &attributes)
    }

    /// A `NULL`-terminated `char *[]` that lives for the duration of `body`.
    private static func withCStrings<R>(
        _ strings: [String], _ body: ([UnsafeMutablePointer<CChar>?]) -> R
    ) -> R {
        let pointers = strings.map { strdup($0) } + [nil]
        defer {
            for pointer in pointers { free(pointer) }
        }
        return body(pointers)
    }
}
```

```swift
import Foundation

/// The servers this app started and has not yet seen exit (D-236).
///
/// **It exists for the case where no cleanup code runs.** A crash, a force
/// quit or a `kill -9` closes the app's pipes, and a server that honours stdin
/// EOF exits by itself — but nothing obliges it to, and `npx`'s `node` child
/// does not see the EOF its parent saw. This file is how the next launch finds
/// what the last one left behind.
///
/// **An entry is reaped only when its owner is dead.** The owner is the app
/// process that spawned the server, identified by pid *and* start time. Without
/// it, `steno mcp-selftest` run from a terminal while the app is open would
/// reap the app's live servers: their leaders are alive and their start times
/// match, which is exactly what an orphan looks like.
final class ProcessLedger: @unchecked Sendable {
    struct Entry: Codable, Equatable {
        let owner: ProcessIdentity
        /// The group leader. Its pid is the group id: `posix_spawn` with
        /// `POSIX_SPAWN_SETPGROUP` and a group of 0 makes the child its own
        /// group's leader.
        let leader: ProcessIdentity
    }

    /// What one reap did, for the launch log line and for tests.
    struct Report: Equatable {
        var killed = 0
        /// The leader's pid now belongs to a process with a different start
        /// time — a stranger. Never signalled.
        var reused = 0
        var alreadyGone = 0
    }

    let fileURL: URL
    private let owner: ProcessIdentity?
    private let lock = NSLock()

    /// - Parameter owner: the identity entries are recorded under. Defaults to
    ///   this process; a test passes a dead identity to manufacture an orphan.
    init(fileURL: URL, owner: ProcessIdentity? = ProcessIdentity.this) {
        self.fileURL = fileURL
        self.owner = owner
    }

    /// `~/Library/Application Support/com.lgabrielgr.steno/mcp-processes.json`.
    ///
    /// **Not in `StenoStore.storeDirectory`,** which is the unit of deletion:
    /// §10.1's Replace mode removes that directory wholesale, and a ledger
    /// inside it would lose the entries for servers that are still running.
    static var defaultURL: URL {
        get throws {
            try FileManager.default.url(
                for: .applicationSupportDirectory, in: .userDomainMask,
                appropriateFor: nil, create: false
            )
            .appendingPathComponent(Log.subsystem, isDirectory: true)
            .appendingPathComponent("mcp-processes.json")
        }
    }

    func record(_ leader: ProcessIdentity) {
        guard let owner else { return }
        update { $0.append(Entry(owner: owner, leader: leader)) }
    }

    func remove(_ leader: ProcessIdentity) {
        update { $0.removeAll { $0.leader == leader } }
    }

    var entries: [Entry] {
        lock.lock()
        defer { lock.unlock() }
        return read()
    }

    /// Kill every group an exited owner left behind, then forget it.
    ///
    /// Run at launch, before any server can start, so a group this reaps can
    /// never be one this process is about to create.
    func reapOrphans(grace: Duration = .seconds(1)) async -> Report {
        let orphans: [Entry] = {
            lock.lock()
            defer { lock.unlock() }
            return read().filter { !$0.owner.isAlive }
        }()

        var report = Report()
        for entry in orphans {
            let pgid = entry.leader.pid
            if let now = ProcessIdentity.current(of: pgid) {
                guard now == entry.leader else {
                    report.reused += 1
                    remove(entry.leader)
                    continue
                }
            } else if !ProcessGroup.hasMembers(pgid) {
                report.alreadyGone += 1
                remove(entry.leader)
                continue
            }
            // Leader alive and ours, or leader dead with members left. The
            // second is ours too: POSIX does not reuse a process group id while
            // the group exists, so a live group with this id is the one we made.
            ProcessGroup.signal(pgid, SIGTERM)
            if await !ProcessGroup.waitUntilEmpty(pgid, timeout: grace) {
                ProcessGroup.signal(pgid, SIGKILL)
                _ = await ProcessGroup.waitUntilEmpty(pgid, timeout: grace)
            }
            report.killed += 1
            remove(entry.leader)
        }
        return report
    }

    private func update(_ change: (inout [Entry]) -> Void) {
        lock.lock()
        defer { lock.unlock() }
        var entries = read()
        change(&entries)
        write(entries)
    }

    /// A missing or unreadable file is an empty ledger: the worst case is a
    /// leak the user can see in Activity Monitor, never a refusal to start.
    private func read() -> [Entry] {
        guard let data = try? Data(contentsOf: fileURL) else { return [] }
        return (try? JSONDecoder().decode([Entry].self, from: data)) ?? []
    }

    private func write(_ entries: [Entry]) {
        do {
            try FileManager.default.createDirectory(
                at: fileURL.deletingLastPathComponent(), withIntermediateDirectories: true)
            try JSONEncoder().encode(entries).write(to: fileURL, options: .atomic)
        } catch {
            Log.mcp.error(
                "process ledger write failed: \(String(describing: error), privacy: .public)")
        }
    }
}
```

```swift
/// The last 64 KB a server wrote to stderr, held in memory and never logged.
///
/// **It is drained because an undrained pipe is a hang** (D-238). A server
/// that writes to stderr faster than anyone reads fills the pipe's buffer and
/// blocks inside that write — no longer answering requests, for a reason
/// unrelated to the request. Draining is the fix; keeping the tail is what
/// makes the drained bytes useful to M5-02's connection test, which can show
/// the user why their server would not start.
///
/// **Never logged** (§8): a server's stderr is where a token in its own
/// environment is most likely to be echoed back.
final class StderrRing: @unchecked Sendable {
    static let capacity = 64 * 1024

    private let lock = NSLock()
    private var bytes = Data()

    func append(_ chunk: Data) {
        lock.lock()
        defer { lock.unlock() }
        bytes.append(chunk)
        if bytes.count > Self.capacity {
            bytes = Data(bytes.suffix(Self.capacity))
        }
    }

    /// Lossy UTF-8, deliberately: the tail may begin mid-character, and the
    /// failable initializer the lint rule prefers would turn that one cut
    /// character into no text at all.
    var text: String {
        lock.lock()
        defer { lock.unlock() }
        // swiftlint:disable:next optional_data_string_conversion
        return String(decoding: bytes, as: UTF8.self)
    }
}
```

```swift
import Foundation

/// One live server process and the JSON-RPC session over its pipes.
///
/// **Every request waits on a continuation, never on a file descriptor**
/// (D-238). `withDeadline` cannot return while its operation ignores
/// cancellation (D-146), and a blocking `read` ignores it — so a design that
/// read the reply inline would let one wedged server hold a refresh pass past
/// any deadline. Here a reader thread feeds `consume()`, `consume()` resolves
/// continuations by id, and a deadline resolves the same continuation from the
/// other side. Whichever arrives first wins; the loser finds nothing to resume.
///
/// **A closed connection stays closed.** The first failure — exit, oversized
/// message, an explicit close — fails every pending request with that reason
/// and every later one immediately. `MCPServer` decides what happens to the
/// process; this type only stops talking to it.
actor MCPConnection {
    let process: SpawnedProcess
    private(set) var negotiatedVersion: String?

    private var nextID = 1
    private var pending: [Int: Pending] = [:]
    private var closeReason: MCPError?
    private var hasExited = false
    private var standardOutputEnded = false
    private let maximumMessageLength: Int
    private let closed: AsyncStream<MCPError>
    private let closedContinuation: AsyncStream<MCPError>.Continuation

    private struct Pending {
        let continuation: CheckedContinuation<JSONValue, Error>
        let timer: Task<Void, Never>
    }

    init(process: SpawnedProcess, stderr: StderrRing, maximumMessageLength: Int) {
        self.process = process
        self.maximumMessageLength = maximumMessageLength
        (closed, closedContinuation) = AsyncStream<MCPError>.makeStream()

        Task { [process] in
            for await chunk in process.standardError { stderr.append(chunk) }
        }
        Task { [weak self, process] in
            _ = await process.exitStatus.value
            await self?.processExited()
        }
        Task { [weak self] in await self?.consume() }
    }

    /// Why this connection closed, once it has.
    func waitUntilClosed() async -> MCPError {
        for await reason in closed { return reason }
        return closeReason ?? .stopped
    }

    /// The `initialize` handshake: request, version check, `initialized`.
    ///
    /// Empty `capabilities`: Steno offers the server no sampling, no roots and
    /// no elicitation, so a server never has a reason to ask for them.
    func initialize(timeout: Duration) async throws {
        let params: JSONValue = .object([
            "protocolVersion": .string(MCPProtocol.requestedVersion),
            "capabilities": .object([:]),
            "clientInfo": .object([
                "name": .string("steno"),
                "version": .string(Self.clientVersion),
            ]),
        ])
        let result = try await request("initialize", params: params, timeout: timeout)
        guard let version = result["protocolVersion"]?.stringValue else {
            throw MCPError.protocolViolation(.malformedResult)
        }
        guard MCPProtocol.supportedVersions.contains(version) else {
            throw MCPError.unsupportedProtocolVersion
        }
        negotiatedVersion = version
        try send(.notification(method: "notifications/initialized", params: nil))
    }

    /// Send a request and wait for its reply, its deadline, or the connection
    /// closing — whichever is first.
    ///
    /// - Throws: `MCPError`, or `CancellationError` when the calling task is
    ///   cancelled.
    func request(_ method: String, params: JSONValue?, timeout: Duration) async throws
        -> JSONValue
    {
        if let closeReason { throw closeReason }
        let id = nextID
        nextID += 1
        let line = try Self.encode(.request(id: id, method: method, params: params))

        return try await withTaskCancellationHandler {
            try await withCheckedThrowingContinuation { continuation in
                // This closure runs on the actor without suspending, and replies
                // are resolved on the actor too — so even a reply that arrives
                // before `write` returns waits until this entry exists. The
                // order of the two lines below is therefore not load-bearing.
                let timer = Task { [weak self] in
                    try? await Task.sleep(for: timeout)
                    guard !Task.isCancelled else { return }
                    await self?.resolve(id, with: .failure(MCPError.timedOut))
                }
                pending[id] = Pending(continuation: continuation, timer: timer)
                process.write(line) { [weak self] accepted in
                    guard !accepted else { return }
                    Task { await self?.resolve(id, with: .failure(MCPError.crashed)) }
                }
            }
        } onCancel: {
            Task { [weak self] in await self?.resolve(id, with: .failure(CancellationError())) }
        }
    }

    /// Fail everything pending with `reason` and refuse anything new.
    func close(_ reason: MCPError) {
        guard closeReason == nil else { return }
        closeReason = reason
        let waiting = pending
        pending.removeAll()
        for entry in waiting.values {
            entry.timer.cancel()
            entry.continuation.resume(throwing: reason)
        }
        closedContinuation.yield(reason)
        closedContinuation.finish()
    }

    // MARK: - Inbound

    private func consume() async {
        var framer = JSONRPCFramer(limit: maximumMessageLength)
        for await chunk in process.standardOutput {
            for output in framer.append(chunk) {
                switch output {
                case .line(let line):
                    handle(line)
                case .oversized:
                    close(.protocolViolation(.oversizedMessage))
                    return
                }
            }
        }
        standardOutputEnded = true
        if hasExited { close(.crashed) }
    }

    /// The leader exited. **Close once its last output is read, not at once:**
    /// a server that writes a reply and then exits has its exit reaped on one
    /// thread while the reply is still in the pipe on another, and closing on
    /// the exit alone would fail a request whose answer had already arrived.
    ///
    /// Bounded, because a grandchild holding stdout open — `npx`'s `node`
    /// child, outliving `npx` — means EOF may never come.
    private func processExited() {
        hasExited = true
        if standardOutputEnded {
            close(.crashed)
            return
        }
        Task { [weak self] in
            try? await Task.sleep(for: .milliseconds(250))
            await self?.close(.crashed)
        }
    }

    private func handle(_ line: Data) {
        switch JSONRPCMessage.decode(line: line) {
        case .response(let id, let result):
            resolve(id, with: .success(result))
        case .errorResponse(let id, let code):
            resolve(id, with: .failure(MCPError.serverError(code: code)))
        case .serverRequest(let id, let method):
            try? send(.serverRequest(id: id, method: method))
        case .notification, .request:
            // Logging, progress and `list_changed` notifications: nothing in
            // M5 acts on them, and a caller re-lists when it needs to.
            break
        case nil:
            // By length only. The line is server output, and §8 keeps server
            // output out of the log.
            Log.mcp.debug("dropped an unparseable line of \(line.count, privacy: .public) bytes")
        }
    }

    /// Resume the request `id` once. A late reply to a request that already
    /// timed out finds no entry and is dropped.
    private func resolve(_ id: Int, with result: Result<JSONValue, Error>) {
        guard let entry = pending.removeValue(forKey: id) else { return }
        entry.timer.cancel()
        entry.continuation.resume(with: result)
    }

    private func send(_ message: JSONRPCMessage) throws {
        process.write(try Self.encode(message)) { _ in }
    }

    private static func encode(_ message: JSONRPCMessage) throws -> Data {
        do {
            return try message.encodedLine()
        } catch {
            // Only a non-finite `Double` in caller-supplied params gets here.
            throw MCPError.protocolViolation(.unencodableRequest)
        }
    }

    private static var clientVersion: String {
        Bundle.main.object(forInfoDictionaryKey: "CFBundleShortVersionString") as? String
            ?? "0"
    }
}
```

```swift
import Foundation

/// One configured MCP server: what callers hold, and the lifecycle policy.
///
/// **Lazy** (D-237): nothing runs until the first request, and then the
/// process stays up until `stop()`, app quit, or a failure. A crash or a
/// timeout drops it back to idle and the next request starts a fresh one —
/// nothing restarts without a caller, so a broken server costs nothing while
/// nobody is asking it anything.
///
/// **A timeout ends the process, not just the request.** A server that missed
/// a deadline is either wedged or too slow to serve a refresh pass, and a
/// wedged one may have stopped reading stdin — leaving a write blocked behind
/// it that only killing the group releases (D-238). Requests in flight on the
/// same process fail with `.stopped`.
///
/// **Three failures inside the window and it stays down** until `restart()`.
/// A failed start, a crash and a timeout each count: a server that hangs every
/// time is the same problem as one that crashes every time, with a slower
/// symptom.
public actor MCPServer {
    public struct Configuration: Sendable {
        /// An `npx` cold start downloads and links before it answers.
        public var startupTimeout: Duration = .seconds(20)
        public var requestTimeout: Duration = .seconds(30)
        public var pingTimeout: Duration = .seconds(5)
        /// Each step of the stop escalation waits this long (D-235).
        public var terminateGrace: Duration = .seconds(1)
        public var failureLimit = 3
        public var failureWindow: Duration = .seconds(60)
        public var maximumMessageLength = JSONRPCFramer.maximumLineLength

        public init() {}
    }

    public enum Status: Equatable, Sendable {
        case idle, starting, ready, failed
    }

    public let definition: MCPServerDefinition
    private let configuration: Configuration
    private let ledger: ProcessLedger
    private let parentEnvironment: [String: String]
    private let stderr = StderrRing()

    private var state = State.idle
    private var failures: [ContinuousClock.Instant] = []
    /// Set by `MCPHost` when it lets go of this server — at quit, or when a
    /// changed definition replaces it. A caller may still hold the reference,
    /// and without this its next request would spawn a process the host no
    /// longer tracks: at quit, a leak; after a replacement, the old command.
    private var isClosed = false

    private enum State {
        case idle
        case starting(Task<MCPConnection, Error>)
        case ready(MCPConnection)
        case failed
    }

    init(
        definition: MCPServerDefinition, configuration: Configuration, ledger: ProcessLedger,
        parentEnvironment: [String: String] = ProcessInfo.processInfo.environment
    ) {
        self.definition = definition
        self.configuration = configuration
        self.ledger = ledger
        self.parentEnvironment = parentEnvironment
    }

    public var status: Status {
        switch state {
        case .idle: .idle
        case .starting: .starting
        case .ready: .ready
        case .failed: .failed
        }
    }

    /// The protocol version the running server agreed to, if one is running.
    public var negotiatedVersion: String? {
        get async {
            guard case .ready(let connection) = state else { return nil }
            return await connection.negotiatedVersion
        }
    }

    /// The tail of what the server wrote to stderr, across restarts — so it
    /// still holds the reason after a crash. Shown to the user by M5-02; never
    /// logged (§8).
    public nonisolated func recentStderr() -> String {
        stderr.text
    }

    // MARK: - Requests

    public func ping() async throws {
        _ = try await perform("ping", params: nil, timeout: configuration.pingTimeout)
    }

    public func listTools() async throws -> [MCPTool] {
        try await paginate("tools/list", key: "tools", MCPTool.init)
    }

    public func listResources() async throws -> [MCPResource] {
        try await paginate("resources/list", key: "resources", MCPResource.init)
    }

    public func callTool(
        _ name: String, arguments: [String: JSONValue] = [:], timeout: Duration? = nil
    ) async throws -> MCPToolResult {
        let result = try await perform(
            "tools/call",
            params: .object(["name": .string(name), "arguments": .object(arguments)]),
            timeout: timeout ?? configuration.requestTimeout)
        guard let toolResult = MCPToolResult(result) else {
            throw MCPError.protocolViolation(.malformedResult)
        }
        return toolResult
    }

    public func readResource(_ uri: String) async throws -> [MCPResourceContents] {
        let result = try await perform(
            "resources/read", params: .object(["uri": .string(uri)]),
            timeout: configuration.requestTimeout)
        guard let contents = result["contents"]?.arrayValue else {
            throw MCPError.protocolViolation(.malformedResult)
        }
        return contents.compactMap(MCPResourceContents.init)
    }

    // MARK: - Lifecycle

    /// Stop the process group, if one is running.
    ///
    /// - Returns: `true` once nothing this server started is still running.
    @discardableResult
    public func stop() async -> Bool {
        switch state {
        case .idle, .failed:
            return true
        case .starting(let task):
            // Cancelled, not awaited: a start can take the whole startup
            // deadline, which is longer than app quit's budget. A cancelled
            // `launch()` tears its own process down; one that finished first
            // hands back a connection that is ours to stop, because the
            // starter sees the state change and leaves it alone.
            state = .idle
            task.cancel()
            guard let connection = try? await task.value else { return true }
            return await shutdown(connection, crashed: false)
        case .ready(let connection):
            state = .idle
            return await shutdown(connection, crashed: false)
        }
    }

    /// Stop, forget past failures, and let the next request start fresh —
    /// the way out of `.failed`. A closed server stays closed.
    public func restart() async {
        await stop()
        failures.removeAll()
        state = .idle
    }

    /// Stop, and refuse every later request with `.stopped`.
    func close() async {
        isClosed = true
        await stop()
    }

    // MARK: - Internals

    private func perform(_ method: String, params: JSONValue?, timeout: Duration) async throws
        -> JSONValue
    {
        let started = ContinuousClock.now
        let connection = try await connection()
        do {
            let result = try await connection.request(method, params: params, timeout: timeout)
            log(method, since: started, outcome: "ok")
            return result
        } catch let error as MCPError {
            log(method, since: started, outcome: "\(error)")
            if error == .timedOut { await drop(connection, countsAsFailure: true) }
            throw error
        }
    }

    private func paginate<Item>(
        _ method: String, key: String, _ make: (JSONValue) -> Item?
    ) async throws -> [Item] {
        var items: [Item] = []
        var cursor: String?
        for _ in 0..<MCPProtocol.maximumPages {
            let params: JSONValue? = cursor.map { .object(["cursor": .string($0)]) }
            let result = try await perform(
                method, params: params, timeout: configuration.requestTimeout)
            guard let page = result[key]?.arrayValue else {
                throw MCPError.protocolViolation(.malformedResult)
            }
            items += page.compactMap(make)
            guard let next = result["nextCursor"]?.stringValue else { return items }
            cursor = next
        }
        throw MCPError.protocolViolation(.paginationRunaway)
    }

    /// The running connection, starting one if there is none.
    ///
    /// Requests that arrive while a start is under way await that start; they
    /// never spawn a second process.
    private func connection() async throws -> MCPConnection {
        if isClosed { throw MCPError.stopped }
        switch state {
        case .ready(let connection):
            return connection
        case .starting(let task):
            return try await task.value
        case .failed:
            throw MCPError.failedRepeatedly
        case .idle:
            let task = Task { try await self.launch() }
            state = .starting(task)
            let connection: MCPConnection
            do {
                connection = try await task.value
            } catch {
                guard case .starting(let current) = state, current == task else {
                    throw MCPError.stopped
                }
                state = .idle
                recordFailure()
                throw error
            }
            // `stop()` ran while this start was under way and owns teardown.
            guard case .starting(let current) = state, current == task else {
                throw MCPError.stopped
            }
            state = .ready(connection)
            watch(connection)
            return connection
        }
    }

    /// Spawn, record, handshake. On any failure the process is torn down
    /// before the error leaves, so a failed start never leaves a process.
    private func launch() async throws -> MCPConnection {
        guard
            let launch = ChildLaunch.resolve(definition, parentEnvironment: parentEnvironment)
        else { throw MCPError.commandNotFound }
        let process = try SpawnedProcess.spawn(launch)
        ledger.record(process.identity)
        Log.mcp.info(
            "spawned server \(self.definition.id, privacy: .public) as group \(process.pid, privacy: .public)"
        )

        let connection = MCPConnection(
            process: process, stderr: stderr,
            maximumMessageLength: configuration.maximumMessageLength)
        do {
            try await connection.initialize(timeout: configuration.startupTimeout)
            return connection
        } catch {
            // Every error, not only `MCPError`: `stop()` cancels a start, and
            // the `CancellationError` that produces must not skip the teardown.
            await connection.close(.stopped)
            if error as? MCPError == .crashed {
                _ = await teardown(process, crashed: true)
                throw MCPError.exitedDuringStartup(status: await process.exitStatus.value)
            }
            _ = await teardown(process, crashed: false)
            throw error
        }
    }

    /// Notice the connection closing on its own — a crash, or an oversized
    /// message — and clean up after it.
    private func watch(_ connection: MCPConnection) {
        Task { [weak self] in
            let reason = await connection.waitUntilClosed()
            await self?.connectionClosed(connection, reason: reason)
        }
    }

    private func connectionClosed(_ connection: MCPConnection, reason: MCPError) async {
        // Not the current connection: `stop()` or `drop` closed it, and is
        // already tearing it down.
        guard case .ready(let current) = state, current === connection else { return }
        state = .idle
        recordFailure()
        Log.mcp.error(
            "server \(self.definition.id, privacy: .public) closed: \(String(describing: reason), privacy: .public)"
        )
        _ = await teardown(connection.process, crashed: reason == .crashed)
    }

    /// Take a connection out of service after a timeout.
    private func drop(_ connection: MCPConnection, countsAsFailure: Bool) async {
        guard case .ready(let current) = state, current === connection else { return }
        state = .idle
        if countsAsFailure { recordFailure() }
        _ = await shutdown(connection, crashed: false)
    }

    private func shutdown(_ connection: MCPConnection, crashed: Bool) async -> Bool {
        await connection.close(.stopped)
        return await teardown(connection.process, crashed: crashed)
    }

    /// End the process group and, once it is confirmed empty, forget it.
    ///
    /// An unconfirmed group keeps its ledger entry, so the next launch reaps
    /// what this one could not.
    private func teardown(_ process: SpawnedProcess, crashed: Bool) async -> Bool {
        let gone =
            crashed
            ? await process.killGroup(timeout: configuration.terminateGrace)
            : await process.terminate(grace: configuration.terminateGrace)
        if gone { ledger.remove(process.identity) }
        return gone
    }

    private func recordFailure() {
        let now = ContinuousClock.now
        failures = failures.filter { now - $0 < configuration.failureWindow } + [now]
        if failures.count >= configuration.failureLimit {
            state = .failed
            Log.mcp.error(
                "server \(self.definition.id, privacy: .public) failed \(self.failures.count, privacy: .public) times; stopped until restart"
            )
        }
    }

    private func log(_ method: String, since started: ContinuousClock.Instant, outcome: String) {
        let elapsed = ContinuousClock.now - started
        Log.mcp.info(
            "\(self.definition.id, privacy: .public) \(method, privacy: .public) \(outcome, privacy: .public) in \(elapsed.formatted(.units(allowed: [.milliseconds])), privacy: .public)"
        )
    }
}
```

```swift
import Foundation

/// Every MCP server this process runs, and the two lifecycle edges of the app.
///
/// **Reaping comes first, structurally** (D-236). The orphan reap starts in
/// `init`, and `server(for:)` awaits it before handing anything out — so no
/// server this process starts can ever be mistaken for, or raced by, the reap
/// of the last process's leftovers.
public actor MCPHost {
    /// The app's host. `AppDelegate` touches it at launch, which starts the
    /// reap, and stops it at quit. Tests build their own with a scratch ledger;
    /// nothing in the test bundle may touch this one.
    public static let shared = MCPHost()

    private let ledger: ProcessLedger
    private let configuration: MCPServer.Configuration
    private let reap: Task<ProcessLedger.Report, Never>
    private var servers: [String: MCPServer] = [:]

    public init() {
        // A home directory Application Support cannot be resolved under is
        // not a real configuration; the temporary directory keeps the ledger
        // working rather than turning that into a refusal to run servers.
        let url =
            (try? ProcessLedger.defaultURL)
            ?? FileManager.default.temporaryDirectory.appendingPathComponent(
                "steno-mcp-processes.json")
        self.init(ledger: ProcessLedger(fileURL: url), configuration: .init())
    }

    init(ledger: ProcessLedger, configuration: MCPServer.Configuration) {
        self.ledger = ledger
        self.configuration = configuration
        reap = Task {
            let report = await ledger.reapOrphans()
            if report != ProcessLedger.Report() {
                Log.mcp.info(
                    "reaped orphans: \(report.killed, privacy: .public) killed, \(report.reused, privacy: .public) pid reused, \(report.alreadyGone, privacy: .public) already gone"
                )
            }
            return report
        }
    }

    /// Wait for the launch reap to finish.
    @discardableResult
    func reapCompleted() async -> ProcessLedger.Report {
        await reap.value
    }

    /// The server for `definition`, created on first use.
    ///
    /// A changed definition under the same id replaces the old server, which
    /// is closed first: its process was started from a command that no longer
    /// describes it, and a caller still holding it must not start another.
    public func server(for definition: MCPServerDefinition) async -> MCPServer {
        await reap.value
        if let existing = servers[definition.id] {
            if existing.definition == definition { return existing }
            await existing.close()
        }
        let server = MCPServer(
            definition: definition, configuration: configuration, ledger: ledger)
        servers[definition.id] = server
        return server
    }

    /// Stop every server in parallel, returning when all are stopped or when
    /// `budget` runs out — whichever is first.
    ///
    /// **Bounded, because app quit waits on it.** A stop that outlives the
    /// budget keeps running until the process exits; its ledger entry is
    /// removed only on a confirmed stop, so the next launch reaps anything it
    /// did not finish.
    public func shutdownAll(budget: Duration = .seconds(3)) async {
        let running = Array(servers.values)
        servers.removeAll()
        guard !running.isEmpty else { return }

        let stops = Task {
            await withTaskGroup(of: Void.self) { group in
                for server in running {
                    group.addTask { await server.close() }
                }
            }
        }
        // Not a timer inside the task group: a group waits for all of its
        // children, so a budget child would make every quick shutdown wait out
        // the whole budget.
        let once = OnceFlag()
        await withCheckedContinuation { (continuation: CheckedContinuation<Void, Never>) in
            Task {
                await stops.value
                if once.claim() { continuation.resume() }
            }
            Task {
                try? await Task.sleep(for: budget)
                if once.claim() { continuation.resume() }
            }
        }
    }
}

/// `true` exactly once, from whichever thread asks first.
private final class OnceFlag: @unchecked Sendable {
    private let lock = NSLock()
    private var claimed = false

    func claim() -> Bool {
        lock.lock()
        defer { lock.unlock() }
        guard !claimed else { return false }
        claimed = true
        return true
    }
}
```

```swift
///
/// **It exists because `make test` can only meet the stub.** The suite denies
/// outbound networking (§9.4, D-012), and an off-the-shelf server — the shape
/// §5.4 actually depends on — arrives through `npx`, which downloads before it
/// runs. Whether a real server agrees to `MCPProtocol.requestedVersion`, and
/// whether stopping it leaves `npx`'s `node` child behind, are facts about the
/// outside world that no stub can establish.
///
/// **It uses a scratch ledger, not the app's.** It needs to read its own entry
/// to learn the process group it then checks is empty, and a scratch file
/// keeps that read from seeing — or a reap from touching — the app's servers.
///

/// were. A server's stderr is where a token from its environment would be
/// echoed (§8), and this output is the kind people paste into a PR.
enum MCPSelftest {
    static func runSynchronously(command: String, arguments: [String]) -> Int32 {
        CLISync.runSynchronously {
            await run(command: command, arguments: arguments)
        }
    }

    static func run(
        command: String, arguments: [String],
        out: @escaping @Sendable (String) -> Void = CLIOutput.standardOut
    ) async -> Int32 {
        let ledger = ProcessLedger(
            fileURL: FileManager.default.temporaryDirectory.appendingPathComponent(
                "steno-mcp-selftest-\(UUID().uuidString).json"))
        let host = MCPHost(ledger: ledger, configuration: MCPServer.Configuration())
        let server = await host.server(
            for: MCPServerDefinition(id: "selftest", command: command, arguments: arguments))

        out("mcp-selftest: \(command) \(arguments.joined(separator: " "))")
        let started = ContinuousClock.now
        do {
            try await server.ping()
        } catch {
            out("mcp-selftest: FAIL — start: \(String(describing: error))")
            if error as? MCPError == .commandNotFound {
                out("  the app resolves commands on PATH=\(ChildLaunch.basePath)")
                out("  pass an absolute path, e.g. \"$(which npx)\"")
            }
            out("  stderr    \(server.recentStderr().utf8.count) bytes (not shown, §8)")
            await host.shutdownAll()
            return 1
        }

        out("  version   \(await server.negotiatedVersion ?? "?")")

            out("mcp-selftest: FAIL — the server is running but the ledger has no entry")
            await host.shutdownAll()
            return 1
        }

            let tools = try await server.listTools()
            out("  tools     \(tools.count): \(tools.map(\.name).joined(separator: ", "))")
        } catch {

            await host.shutdownAll()

        } catch {
            out("  resources not offered (\(String(describing: error)))")
        }

        let stopping = ContinuousClock.now
        let stopped = await server.stop()
        out("  stopped   \(milliseconds(since: stopping)) ms")
        // The check the stub cannot make: a real `npx` group, grandchild and all.
        guard stopped, !ProcessGroup.hasMembers(group), ledger.entries.isEmpty else {
            out("mcp-selftest: FAIL — process group \(group) still has members after stop")
            return 1
        }
        out("mcp-selftest: PASS — group \(group) is empty")
        return 0
    }

    private static func milliseconds(since start: ContinuousClock.Instant) -> Int64 {
        let elapsed = ContinuousClock.now - start
        return elapsed.components.seconds * 1000 + elapsed.components.attoseconds
            / 1_000_000_000_000_000
    }
```

```diff
+### D-237 — Lazy start; a timeout ends the process; three failures and it stays down
+**2026-10-09** · M5-01 · **Status:** accepted
+
+`MCPServer` starts on its first request and keeps the process until `stop()`, app quit, or a
+failure. Concurrent first requests share one start. **A timeout ends the process**, not only the
+request. A failed start, a crash and a timeout each count as a failure; three inside 60 s and the
+server is `.failed`, throwing `.failedRepeatedly` until `restart()`. `stop()` during a start cancels
+it rather than awaiting it. **A server `MCPHost` lets go of is closed**, at quit or when a changed
+definition replaces it: every later request throws `.stopped` and nothing is spawned.
+
+**Why:** callers come in bursts (launch, Prepare, the scheduled pass) with idle time between, so
+nothing should run or restart without a caller. A server that missed a deadline is wedged or too
+slow for a refresh pass; a wedged one may have stopped reading stdin, leaving a write blocked that
+only killing the group releases (D-238). A server that hangs every time is the same problem as one
+that crashes every time, so timeouts count — which is why the error is not named `crashLoop`, as the
+design first had it. Cancelling a start matters at quit: the startup deadline (20 s) is longer than
+quit's whole budget (3 s). Closing was found while listing inputs no test exercised: a refresh pass
+still running at quit holds an `MCPServer` reference, and its next request would have spawned a
+process after `shutdownAll` — a leak at quit, and the *old* command after a replacement.

+**Alternatives:** eager start with auto-restart (costs memory all day, restarts with nobody
+asking); spawn per pass (an `npx` cold start, measured ~1 s warm, eats the refresh deadline: measured at ~1 s with the package already cached, longer on a first

+### D-238 — Requests wait on continuations; writes block on a queue of their own; stderr is drained
+**2026-10-09** · M5-01 · **Status:** accepted
```
